State glyphs — automatic / by hand / off

Today these states are colour-only. Each gets a shape so the chip still reads in greyscale: a loop for the automation, a person for a hand override, a struck-out circle for off. Drawn at stroke 2 (the library's favicon-cut instinct: bolder strokes below 16 px). The glyph inherits the chip's semantic colour — shape and colour now carry the same message.

Monochrome fallback — no --icon-accent set
