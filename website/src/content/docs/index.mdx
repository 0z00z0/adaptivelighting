## Install

```bash
dotnet add package AdaptiveLighting
dotnet add package AdaptiveLighting.Web   # optional: dashboard + config editor
```

The engine references no generated entity types — it is written against `IHaContext`, `IHaRegistry` and
`IScheduler` — so it runs against any Home Assistant instance. Nothing is hard-coded: no entity ids,
thresholds, times or room names exist in the C#.

:::caution[The web UI has no authentication]
The dashboard is built for a **LAN-only** deployment. Anyone who can reach its port can rewrite your
lighting configuration. Do not port-forward it. If you need it from outside, put it behind Home Assistant
ingress or an authenticating reverse proxy. The engine itself has no network surface — skip
`AdaptiveLighting.Web` if you don't want a UI.
:::
